# 🍟 Natalie's Annulaire — Le Braquage du Mc'Do de Tassin la Demi-Lune (Lyon) 🍟

> **The Legendary Mc'Do Troll Heist**  
> Set in **Tassin la Demi-Lune (Lyon, France)**: Infiltrate an impeccably clean, spotless Mc'Do run by 7 legendary, hardworking employees. Survive deceptive psychological word fights against corporate traps, extract Natalie's 2019 fossilized severed annulaire from the walk-in freezer, and package it into a 24K Golden Happy Meal Box until she **EXPLODES into 90 flying golden McNuggets at 9000 PSI!**

---

## 🚀 How to Run the Game

1. **Via Python local server**:
   ```bash
   cd ~/natalies-finger
   python3 game.py
   ```
   Open [http://localhost:8085](http://localhost:8085) in your web browser.

2. **Or open directly in any modern browser**:
   ```bash
   google-chrome ~/natalies-finger/index.html
   ```
